# FCN 條款評估工具

輸入券商報給你的 FCN（Fixed Coupon Note，固定配息票據）條款，用歷史股價實證回測，
直接回答**「這個配息夠不夠賠你歷史上會踩到的雷」**。

👉 **線上使用：https://henry3556108.github.io/fcn-tool/**

單一 HTML 檔、資料內嵌、無外部資源、不連網、不蒐集任何資料。
也可以直接下載 `index.html` 雙擊開啟離線使用。

## 它在算什麼

FCN 的三個價位都以**期初價（定價日收盤）= 100%** 為基準：

```
  65%          75%                    95%       100%
   │            │                      │          │
下限價        轉換價                 上限價KO    期初價
(KI/EKI)     (Strike)              (提前贖回)
```

- **上限價 KO** — 每月觀察，籃子裡全部標的收盤都 ≥ 此價位就提前贖回，拿回本金 + 已配息。
- **轉換價 Strike** — 真的要接股票時，用這個價位接（不是市價）。
- **下限價 KI / EKI** — 觸發賠錢的開關。沒碰到就照領配息、拿回本金。
  勾選 EKI 代表歐式：**只看最終評價日當天收盤**，中途跌破再彈回來不算。

下限價與轉換價之間的落差是「懸崖」：一旦觸發，就是用轉換價接一檔市價更低的股票，
觸發當下即認列損失，不存在剛好打平的情況。

### 核心輸出：安全倍數

```
安全倍數 = 券商報價月配息 ÷ 打平月配息
```

「打平月配息」= 期望轉股損失攤到平均存續期後的公平價。判準：

| 安全倍數 | 結論 |
|---|---|
| ≥ 3× | ✅ 值得做（歷史實證支持）|
| 1.5 – 3× | ⚠️ 邊緣，建議議價 |
| < 1.5× | ❌ 配息蓋不住歷史實證損失 |

### 雙窗口對照

同一組條款會用兩個歷史區間各算一次，**結論取較差的那個**：

- **近期窗** — 真實籃子的共同歷史，受最短歷史標的限制（如 ARM 2023-09 才上市）。
- **壓力窗** — 只取有 15 年以上歷史的標的組成對照籃子，**含 2008 金融海嘯、2022 熊市**。

近期窗若不含熊市，數字會嚴重偏樂觀——這正是雙窗口存在的理由。

### 其他功能

- 雙窗風險表：提前贖回機率、平均存續期、轉股觸發機率、觸發時平均虧損、最壞單張報酬
- 部位上限建議：由最壞情境反推「這張最多能壓總資產幾 %」
- 備選條款公平配息表：議價彈藥，看壓低下限價／轉換價各能換到多少
- 下限價敏感度表
- 第二分頁：單檔股票勝率回測（N 個交易日內是否跌破 X%，含 SPY 均線濾網）

## ⚠️ 免責聲明

**本工具僅供教育與研究用途，不構成任何投資建議、要約或招攬。**

- 所有數字都是**歷史情境掃描**，不是未來的預測，也不是信賴區間。
  回測視窗高度重疊、樣本並不獨立，統計意義有限。
- 歷史資料**無法涵蓋比回顧期更極端的事件**。壓力窗雖含 2008／2022，
  仍不包含籃子中新上市標的自身崩跌的情境，真實尾部風險只會**更高**。
- 模型**未計入**：發行人（券商）信用風險、存續期間無法中途出場、
  稅費、匯率變動、實際條款中的其他細項。
- 頁面內嵌的股價為**產檔當下的快照，不會自動更新**，也不保證正確或完整。
  資料來源為 Yahoo Finance 公開歷史股價，僅供研究參考。
- 實際下單請以**券商正式條款文件**為準，本工具的條款欄位只是簡化模型。
- 使用者需自行判斷並**自負全部投資風險**，作者不對任何損失負責。
